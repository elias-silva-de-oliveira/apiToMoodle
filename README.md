# Introduction

Moodle is a widely used *Learning Management System* (LMS) that enables
educators to distribute diverse learning materials and conduct student
assessments. This project introduces an *Application Programming
Interface* (API) Gateway designed to facilitate seamless data exchange
with the platform (Oliveira et al. 2021).
